# KOMA Studio

ブラウザで動く日本語の手描き2Dアニメーションエディターです。React、TypeScript、Vite、Canvas 2D API を使用しています。描画、保存、書き出し、清書デモはブラウザ内で行います。AI 清書は同じ PC の ComfyUI で実行します。

## 起動

Node.js 22.18 以上を使用します。

```sh
npm ci
npm run dev
```

ターミナルに表示される URL（通常は http://localhost:5173/）を PC のブラウザで開きます。

```sh
npm test        # モデル、入力検証、再生位置の単体テスト
npm run build   # 型チェックと本番ビルド（dist/）
npm run preview # ビルド結果をローカルで確認
```

## 操作

- 白い 1920 × 1080 のキャンバスにマウスやペンで描画できます。対応ペンの筆圧はストロークに保存されます。
- 右の「線」で太さ、「色」で描画色を設定します。左のツールバーからも色を選べます。
- 「コマを追加」で空白のコマが入ります。複製、削除、クリックやドラッグによるコマ選択、フレーム番号表示に対応しています。
- オニオンスキンは初期状態で前のコマを25%で表示します。次のコマも選択でき、濃さを調整できます。
- タイムラインで再生・停止、ループ、FPS を設定します。初期値は12 fpsです。
- 「保存」で JSON をダウンロードし、「開く」で読み込んで編集を再開します。「書き出し」では現在のコマの原寸 PNG と、長辺最大 640 px の GIF を作成できます。補助表示はどちらの画像にも含まれません。

| 操作 | ショートカット |
| --- | --- |
| ペン / 消しゴム / 移動 | B / E / H |
| 一時的に移動 | Space + ドラッグ、または中ボタンドラッグ |
| ズーム | キャンバス上でホイール |
| 前・次のコマ | ← / → |
| Undo / Redo | Ctrl または ⌘ + Z / Ctrl または ⌘ + Shift + Z |
| 保存 | Ctrl または ⌘ + S |

## データ構造

`src/model.ts` がバージョン付き JSON、検証、履歴を定義します。コマとストロークには一意の ID があり、点列、色、太さ、ツール、任意の筆圧を保持します。複製は新しい ID と独立した点列を作成します。`src/render.ts` がデータを Canvas に描画し、`src/playback.ts` が再生時刻を管理します。

Undo / Redo の保持上限は80操作です。読み込み上限は64 MB、フレーム数上限は1,000です。AI 補正、着色、補間、動作テンプレート、レイヤーと AI 編集ロックは将来の実装範囲です。

## Vercel

Vercel の New Project から `caljun/animeapp` をインポートします。リポジトリルートの `vercel.json` に Vite、`npm ci`、`npm run build`、出力先 `dist` を設定しています。静的な Vercel 版では描画と清書デモが動作します。実モデルを使う場合は下記のローカル起動手順を使います。

## 範囲選択・線画編集

1. 左の「選択」（V）を選び、右の「線」タブで「矩形」または「投げ縄」を選びます。囲いに触れるペン線がストローク単位で選択されます。クリックでは1本を選択します。
2. 選択枠の内側からドラッグすると移動します。Shift を押しながらドラッグすると、枠の内側からでも囲い直せます。Esc または「選択解除」で解除します。
3. 「線」タブで拡大・縮小、回転、色、太さ、複製、削除を操作できます。拡大・縮小率と回転角は現在の形に対する相対値で、選択した編集可能な線の中心を基準に変形します。
4. 「線を整える」から元の線・弱い補正・強い補正を切り替えて比較し、「適用」で確定します。補正は端点と筆圧を保ち、中間点の移動量を制限します。
5. 「固定」で選択した線を線画編集と補正から保護します。選択した固定線は琥珀色の枠で表示され、「固定解除」で編集を再開できます。

選択は現在のコマのベクター線が対象です。オニオンスキンと消しゴムのマスクは選択対象に含まれません。消しゴムはキャンバス上の見た目をマスクするため、消された箇所も選択判定には元の点列を使用します。固定の有無はストロークの任意項目 `locked` として保存し、旧 JSON も読めます。部分ストロークの切り出しは今後の実装範囲です。


## ローカル AI 線画清書

Stable Diffusion 1.5（FP16）と ControlNet 1.1 Scribble（FP16）を、ComfyUI の標準ノードで実行します。有料 API、アカウント、API キーは不要です。初回セットアップでは依存パッケージとモデルをダウンロードします。セットアップ後、ラフと推論データは同じ PC 内で処理されます。

### Apple Silicon Mac のセットアップ

Apple Silicon、統合メモリ16 GB以上、空き8 GiB以上をこの手順の目安にしています。Node.js 22.18 以上、Git、Python 3 が必要です。

```sh
npm ci
bash scripts/setup-comfyui-mac.sh
```

セットアップは ComfyUI と Python 仮想環境を Git 管理外の `.comfyui/` に置き、配布元の SHA-256 と各モデルを照合します。ダウンロードは計約2.85 GBです。[ComfyUI 公式インストールガイド](https://github.com/Comfy-Org/ComfyUI/blob/master/docs/installation.md) · [Stable Diffusion 1.5](https://huggingface.co/Comfy-Org/stable-diffusion-1.5) · [ControlNet Scribble](https://huggingface.co/lllyasviel/control_v11p_sd15_scribble) · [FP16 の配布元](https://huggingface.co/comfyanonymous/ControlNet-v1-1_fp16_safetensors)

ターミナルを2つ開き、プロジェクトのルートで次を1つずつ起動します。

```sh
bash scripts/start-comfyui.sh
npm run dev
```

Vite が表示する `http://127.0.0.1:5173/` を開きます。5173が使用中の場合は Vite が表示する次のポートを使います。ComfyUI はオフラインモードで `127.0.0.1:8188` のみに待ち受けます。ポートを変える場合は両コマンドに同じ `KOMA_COMFY_PORT` を指定します。ブラウザから ComfyUI への通信は Vite のローカルの中継を経由します。停止はそれぞれのターミナルで Ctrl+C です。

### 操作

1. 「選択」で範囲を指定し、「線」タブで補正の強さを調整して「AIで清書」を押します。
2. A（ラフに忠実）、B（滑らかに整理）、C（大きく補正）を比較します。512×512 のラフから、補正設定の異なる3候補を1枚ずつ推論します。
3. キャンバスでベクター化の結果を確認し、「適用」で確定します。「変換前の画像を比較」から生成画像も確認できます。
4. 適用後も線はペン線として選択・変形できます。選択範囲外と固定線を保護し、元のラフは Undo で戻せます。JSON の `roughs` にも保存されます。

ComfyUI が未起動、またはモデルが見つからない場合は起動状況を画面に表示します。「デモで試す」は通常の平滑化と線抽出です。ComfyUI は選択画像を `.comfyui/input/koma/` にローカル保存します。ComfyUI が生成した比較画像は作業用の一時ファイルです。

### ベクター化の限界

二値化・微小ノイズ除去・細線化を行い、中心線と幅をストロークの点列、太さ、筆圧に変換します。極細の線は欠けることがあり、交点は複数のストロークに分割されます。元のラフに対して構図が変わることもあります。比較画像はプレビュー専用です。適用後のプロジェクトには編集可能なストロークと元ラフが保存されます。
