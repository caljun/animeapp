# KOMA Studio

ブラウザで動く日本語の手描き2Dアニメーションエディターです。React、TypeScript、Vite、Canvas 2D API を使用しています。描画、保存、書き出し、清書デモはブラウザ内で行います。AI 清書を実行する場合は、選択領域の画像をサーバー経由で画像編集サービスに送信します。

## 起動

Node.js 22.18 以上を使用します。

```sh
npm ci
npm run dev
```

ターミナルに表示される URL（通常は http://localhost:5173/）を PC のブラウザで開きます。

```sh
npm test        # モデル、入力検証、再生位置の単体テスト
npm run build   # 型チェックと本番ビルド（dist/）
npm run preview # ビルド結果をローカルで確認
```

## 操作

- 白い 1920 × 1080 のキャンバスにマウスやペンで描画できます。対応ペンの筆圧はストロークに保存されます。
- 右の「線」で太さ、「色」で描画色を設定します。左のツールバーからも色を選べます。
- 「コマを追加」で空白のコマが入ります。複製、削除、クリックやドラッグによるコマ選択、フレーム番号表示に対応しています。
- オニオンスキンは初期状態で前のコマを25%で表示します。次のコマも選択でき、濃さを調整できます。
- タイムラインで再生・停止、ループ、FPS を設定します。初期値は12 fpsです。
- 「保存」で JSON をダウンロードし、「開く」で読み込んで編集を再開します。「書き出し」では現在のコマの原寸 PNG と、長辺最大 640 px の GIF を作成できます。補助表示はどちらの画像にも含まれません。

| 操作 | ショートカット |
| --- | --- |
| ペン / 消しゴム / 移動 | B / E / H |
| 一時的に移動 | Space + ドラッグ、または中ボタンドラッグ |
| ズーム | キャンバス上でホイール |
| 前・次のコマ | ← / → |
| Undo / Redo | Ctrl または ⌘ + Z / Ctrl または ⌘ + Shift + Z |
| 保存 | Ctrl または ⌘ + S |

## データ構造

`src/model.ts` がバージョン付き JSON、検証、履歴を定義します。コマとストロークには一意の ID があり、点列、色、太さ、ツール、任意の筆圧を保持します。複製は新しい ID と独立した点列を作成します。`src/render.ts` がデータを Canvas に描画し、`src/playback.ts` が再生時刻を管理します。

Undo / Redo の保持上限は80操作です。読み込み上限は64 MB、フレーム数上限は1,000です。AI 補正、着色、補間、動作テンプレート、レイヤーと AI 編集ロックは将来の実装範囲です。

## Vercel

Vercel の New Project から `caljun/animeapp` をインポートします。リポジトリルートの `vercel.json` に Vite、`npm ci`、`npm run build`、出力先 `dist` を設定しています。描画と清書デモは環境変数なしで動作します。AI 清書の設定は下記を参照してください。

## 範囲選択・線画編集

1. 左の「選択」（V）を選び、右の「線」タブで「矩形」または「投げ縄」を選びます。囲いに触れるペン線がストローク単位で選択されます。クリックでは1本を選択します。
2. 選択枠の内側からドラッグすると移動します。Shift を押しながらドラッグすると、枠の内側からでも囲い直せます。Esc または「選択解除」で解除します。
3. 「線」タブで拡大・縮小、回転、色、太さ、複製、削除を操作できます。拡大・縮小率と回転角は現在の形に対する相対値で、選択した編集可能な線の中心を基準に変形します。
4. 「線を整える」から元の線・弱い補正・強い補正を切り替えて比較し、「適用」で確定します。補正は端点と筆圧を保ち、中間点の移動量を制限します。
5. 「固定」で選択した線を線画編集と補正から保護します。選択した固定線は琥珀色の枠で表示され、「固定解除」で編集を再開できます。

選択は現在のコマのベクター線が対象です。オニオンスキンと消しゴムのマスクは選択対象に含まれません。消しゴムはキャンバス上の見た目をマスクするため、消された箇所も選択判定には元の点列を使用します。固定の有無はストロークの任意項目 `locked` として保存し、旧 JSON も読めます。部分ストロークの切り出しは今後の実装範囲です。


## AI 線画清書

1. 「選択」で範囲を指定し、「線」タブで補正の強さを調整します。
2. 接続済みの場合はアクセスコードを入力して「AIで清書」を押します。未接続でも「デモで試す」から無料で操作を確認できます。デモはローカルの平滑化と線抽出です。
3. A（ラフに忠実）、B（滑らかに整理）、C（大きく補正）から候補を選びます。キャンバスには適用予定のストロークが表示され、「変換前の画像を比較」で元の候補画像を確認できます。
4. 「適用」で確定します。元のラフは Undo で戻せるほか、保存ファイル内のコマの `roughs` に保管されます。保存後にアーカイブを取り出す専用画面はありません。

### モデルと接続

[GPT-Image-2.5 Flare](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare) の [Image Edits API](https://developers.openai.com/api/reference/python/resources/images/methods/edit) を使用します。画像・透過マスク入力に対応しており、低品質設定の正方形画像を3つの指示で並行生成します。選択したコマから描画とマスクを作り、固定線・対象外の線の領域を保護します。オニオンスキンや他のコマは送信しません。サーバーでプロバイダーを呼び出す処理は `server/cleanup.mjs` にあり、将来のローカル推論でも同じ入出力を実装できます。

- ローカルは `.env.example` を `.env.local` にコピーし、`OPENAI_API_KEY` に画像編集を利用できる課金済み OpenAI プロジェクトのキーを設定します。`KOMA_AI_ACCESS_TOKEN` には16文字以上の推測しにくいアクセスコードを設定し、`npm run dev` を再起動します。
- Vercel は Project Settings の Environment Variables に同じ2項目を登録し、再デプロイします。`/api/cleanup` の Vercel Function が呼び出されます。実行時間の設定には Fluid Compute を使用します。OpenAI API キーに `VITE_` 接頭辞を付けず、ブラウザには清書用アクセスコードだけを入力します。

### ベクター化の範囲

画像を二値化し、微小ノイズ除去、中心線の細線化、端点・分岐ごとのパス追跡を行います。線幅は距離場から推定して太さと筆圧に変換します。選択境界はキャンバス座標で適用し、範囲外に続くラフをクリップ付きのストロークとして残します。画像は比較表示用で、適用・保存される清書はストロークです。

薄い線、細かい点、密な交差、面塗り、極端な太さの変化は、欠落や複数の線への分割が起こり得ます。モデルが構図をずらす場合もあるため、確定前に変換前画像とキャンバスを比較してください。実モデルの呼び出しは、この開発環境に API キーがないため未検証です。
